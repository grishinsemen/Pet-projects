# Пользовательские истории

Формат: **Как** [роль], **я хочу** [действие], **чтобы** [ценность].
Критерии приёмки пишем в виде «Дано, Когда, Тогда».

## US-01. Название

Как [роль], я хочу [действие], чтобы [ценность].

**Критерии приёмки**

1. Дано [начальное состояние], когда [действие], тогда [результат].
2. Дано [состояние], когда [ошибочное действие], тогда [реакция системы].

**Связанные требования:** FR-01
